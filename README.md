# 🌿 BAU Horticulture Graduate Repository

Monorepo for Department of Horticulture, Bangladesh Agricultural University (BAU), Mymensingh.

---

## 📂 Sub-Projects

### 1. [`MS_HORT_BAU`](./MS_HORT_BAU)
Unified, zero-login academic portal for M.S. Horticulture students and teachers:
* **Weekly Class Routine**: Real-time schedule by day (Course + Teacher Initials).
* **Teaching Materials Vault**: Direct Google Drive organization for lecture slides, handbooks, and reference literature.
* **Deadlines & Reminders**: Active countdown tracker for assignments and term papers with 1-click Google/Apple Calendar integration.

### 2. [`Dictionary_and_Study_Materials`](./Dictionary_and_Study_Materials)
Lexicographical reference and active-recall exam review systems:
* **Master Lexicographical Dashboard**: 11-column botanical dictionary (`app.py`).
* **HortiPrep Flashcard System**: Graduate exam review and spaced repetition (`study_app.py`).
* **Ollama Botanical LLM Pipeline**: Local AI synthesis (`fill_dictionary_ollama.py`).
